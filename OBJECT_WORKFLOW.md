New Checklist
- [ ] In Blender, apply all transformations
- [ ] In Blender, export using the "Godot" export template
- [ ] In Godot, (optionally) create a PostImport.cs next to the .glb if you want to add custom logic (like setting the materials). If not, the fallback at ImportScripts/GlbPostImport.cs will be set as the import script.
- [ ] In Godot, right-click .glb and choose "Create Inherited Scene from GLB" (custom plugin)
- [ ] In Godot, optionally add features to the inherited scene under the rigid body (if it has one)

Old Checklist
- [ ] In Blender, apply all transformations
- [ ] In Blender, export using the "Godot" export template
- [ ] In Godot, open .glb and set import script
- [ ] In Godot, right click .glb and choose "new inherited scene"
- [ ] In Godot, save the new scene next to the .glb
- [ ] In Godot, optionally add features to the inherited scene under the rigid body (if it has one)
